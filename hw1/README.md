# ДЗ 1. Выбор датасета

Датасет: [Used Cars Dataset (Craigslist)](https://www.kaggle.com/datasets/austinreese/craigslist-carstrucks-data), только Калифорния.
Целевой признак `condition` (состояние машины, 6 классов), задача классификации.

Требования: 2000 <= N <= 100000, d >= 10 и хотя бы 3 условия из 5 (пропуски, разнородные признаки, несбалансированные классы,
много выбросов, текстовые признаки).

Что делает `lab1.py`: при необходимости скачивает датасет через kagglehub, читает его кусками и сохраняет срез по Калифорнии,
убирает id, ссылки, VIN, пустые и константные столбцы и строки без `condition`, потом считает N, d, K, доли классов,
пропуски и выбросы и проверяет условия.

```
python hw1/lab1.py
```
